# AI-администратор сети салонов

Проект обновлён на основе исходных `bot.py`, `requirements.txt`, `knowledge.txt` и `start.sh`. Существующая «Студия красоты Оксаны Ким» уже добавлена в отдельную SQLite-базу; Groq и модель `openai/gpt-oss-20b` сохранены. Требуется Python 3.11+.

## Запуск

Распакуйте архив и откройте терминал в папке с `bot.py`:

```bash
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните `TELEGRAM_TOKEN`, `GROQ_API_KEY`, `BOT_USERNAME` (имя без `@`). Не загружайте `.env` в общедоступные места. Затем:

```bash
python bot.py run
```

`start.sh` запускает ту же команду на Linux. Из терминала будут видны ошибки запуска; двойной щелчок по Python-файлу закрывает окно сразу после остановки программы.

## Добавить новый салон

Создайте для него текстовый файл со сведениями. Разделяйте темы пустой строкой. Выполните:

```bash
python bot.py add-salon --name "Название салона" --district "Центральный" --address "Калининград, ул. Примерная, 10" --knowledge salon2.txt
```

Допустимые районы: `Центральный`, `Ленинградский`, `Московский`. Бот показывает только салоны Калининграда. Команда выдаст личную ссылку `https://t.me/ИМЯ_БОТА?start=s_...`. QR-код должен содержать эту ссылку. Список кодов, районов и адресов можно посмотреть командой `python bot.py list-salons`. Исходный `knowledge.txt` оставлен как копия сведений первого салона; бот читает сведения из `data/`, изменение одного текстового файла после импорта само по себе базу не обновляет.

При `/start` пользователь получает кнопки трёх районов и кнопку поиска по названию. Поиск из меню районов выполняется по всему Калининграду. После выбора района поиск ограничивается этим районом. Кнопки салонов содержат название и точный адрес.

После выбора салона доступны `Каталог услуг`, `Записаться к мастеру`, `Задать вопрос` и смена салона. Каталог автоматически формируется из строк базы знаний с названием и ценой. Запись к мастеру пока не создаёт заявку и сообщает, что функция будет добавлена позже. Ответ на вопрос получает сведения только из отдельной БД выбранного салона. Команда `/salon` оставлена как дополнительный способ вернуться к выбору района.

Чтобы изменить район или адрес уже добавленного салона:

```bash
python bot.py set-location --salon-id ИДЕНТИФИКАТОР --district "Ленинградский" --address "Калининград, ул. Флотская, 9"
```

## Структура

- `bot.py` — точка входа, `salon_bot/cli.py` — сборка зависимостей и регистрация салонов.
- `salon_bot/domain.py` — сущности и интерфейсы для замены хранилища, поиска и модели.
- `salon_bot/store.py` — каталог, поиск по названию и району, услуги, сессии и SQLite-базы салонов.
- `salon_bot/service.py` — кнопочные сценарии и привязка каталога/вопросов к нужной базе.
- `salon_bot/ai.py` — адаптер Groq; `salon_bot/telegram.py` — команды и кнопки Telegram.
- `data/catalog.sqlite3` — каталог и сессии; `data/salons/*.sqlite3` — отдельные сведения каждого салона. Сохраняйте `data/` при обновлении приложения и делайте резервные копии.

Это базовая реализация для личных чатов и одного процесса polling. Перед запуском на большое число клиентов понадобятся администрирование данных с авторизацией, мониторинг, лимиты, очередь задач и переход на серверную БД при росте нагрузки. Подтверждения реальной записи пока нет — необходима интеграция с системой записи салона.
